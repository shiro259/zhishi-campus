# 知食校园（zhishi-campus）

校园食堂智能选餐助手（微信小程序，学生端）。**把“今天吃什么”从到窗口前盲目排队，变成出发前 30 秒内有依据的决策。**

本仓库当前处于**设计阶段**（实验3：软件架构与界面设计）。实验2 的需求基线（需求说明V1、用例、验收示例 V1—V5）在本文档与 `docs/design/` 中被引用，代码尚未开始编写（实验4 起进入开发）。

## 设计要点（与需求的对应）

- **一条核心流程**：设置画像 → 维护/选择当日菜单 → 获得 AI 推荐 Top3 与理由 → 忌口确认并记录 → 反馈 → 偏好更新。
- **架构**：分层 + 模块化（表现层 P1—P5 与组件 C1/C2、业务层 M1—M6、数据层 D1—D4、AI 接入与降级控制层 A1—A3），详见 `docs/design/modules.md`。
- **AI 边界**：模型只做“在候选集合内挑选 3 道并写出理由”；安全判断不交给模型（只提示“可能含有 X，请向窗口确认”，程序侧拦截确定性表述，用户强制确认）。
- **降级**：规则推荐是**每次都先算好的基线**，AI 结果只作为覆盖；超时、报错、超额、输出不合规都只是“不覆盖基线”，核心流程不中断。
- **隐私**：数据只存本机，不采集学号、姓名、位置与照片；上传给模型的只有候选菜品与画像标签摘要（不含忌口清单全文）。

## 重新生成图示

图形由 PowerShell + .NET GDI+ 脚本绘制（无需浏览器与联网，Windows 自带 Windows PowerShell 即可）：

```powershell
powershell -File .\tools\render-arch.ps1
powershell -File .\tools\render-data-flow.ps1
powershell -File .\tools\render-ui.ps1
```

> 注意：三个脚本必须以 **UTF-8 BOM** 保存，否则 Windows PowerShell 5.1 会把中文读成乱码。
