# 需求说明V1（知食校园）— v0.1 初稿

> **版本：v0.1（第2周初稿）**。此版本保留**已被删除或修改的需求**，用于核验需求变化过程；请勿删除本版本的历史记录。
> 变更记录：v0.2 将落实需求变化 R1—R5（见本文件末尾的修订清单）。

## 一、功能需求（初稿）

- **FR-01 画像设置**：学生可设置口味偏好、忌口/过敏清单、健康目标与预算区间。
- **FR-02 菜单维护**：可粘贴/导入当日菜单文本并手动修正。
- **FR-03 菜品浏览**：可查看当日候选菜品与价格。
- **FR-04 排队地图**：可查看各食堂/窗口的**实时排队人数与预计等待时间**，用于避峰。
- **FR-05 AI 推荐**：AI 根据画像与候选菜品生成推荐，**输出 5 条**。
- **FR-06 营养信息**：AI 输出每道菜的**精确热量数值**（如 412 kcal）与主要营养素。
- **FR-07 过敏原判定**：由 **AI 判断**某道菜**是否含**用户忌口/过敏食材，并给出结论。
- **FR-08 记录与反馈**：记录今日就餐，可就餐后反馈"符合/不符合口味"。

## 二、非功能需求（初稿，待细化）

- 响应要快、体验要好、界面要简洁。
- 数据要安全。

> 注：以上写法不可验证（无指标、无判定方法），v0.2 起改写为可测指标。

## 三、待解决问题（初稿提出）

1. 排队数据从哪里来？（暂定"由学生或窗口人工上报"）
2. 精确热量数据从哪里来？（暂定"由 AI 估算"）
3. AI 判定过敏原是否可靠？

## 四、修订清单（v0.2 将处理）

| 编号 | 涉及条目 | 计划变更 |
| --- | --- | --- |
| R1 | FR-04 | 删除排队实时地图；改为"错峰时段静态提示" |
| R2 | FR-06 | 精确热量 → 热量区间 + 置信度 + "估算，不用于医学用途" |
| R3 | FR-07 | AI 判定 → 仅提示"可能含有 X，请向窗口确认" + 强制人工确认 |
