## 一句话边界

AI 只负责"在候选菜品里挑 3 条并给出一句理由"；**任何"能不能吃"的安全判断都不交给 AI**，只输出"可能含有 X，请向窗口确认"。模型不可用时自动降级为规则排序，核心流程不中断。
